# Psychologist Landing Template

Full-stack шаблон сайта, CRM и системы онлайн-записи для психологов и других частных специалистов.

Проект начинался как коммерческий landing-шаблон, но постепенно вырос в более полноценную продуктовую основу: публичный сайт, CRM-админка, онлайн-запись, расписание, отзывы, пакеты сессий, напоминания и базовая платежная архитектура.

## Кратко о проекте

Проект представляет собой не статичный лендинг, а переиспользуемую full-stack основу для частных специалистов и небольших сервисных проектов: с публичным сайтом, CRM, онлайн-записью, расписанием, отзывами и настраиваемыми модулями.

В проекте реализованы:

* публичный адаптивный сайт специалиста;
* отдельная страница онлайн-записи `/book`;
* CRM-админка для заявок, клиентов, услуг, пакетов, сессий, заметок, расписания и отзывов;
* ручное создание клиентов, сессий, услуг и пакетных планов в админке;
* возможность выдавать клиенту пакет услуг и использовать его при последующих записях;
* публичные отзывы с проверкой клиента, модерацией и управлением порядком показа;
* пакетные услуги и запись по коду пакета;
* настройки рабочего расписания, исключений по датам, блокировок времени и перерывов между сессиями;
* опциональный интерактивный премиум-календарь “Планировщик” (scheduler) с режимами день / неделя / месяц;
* создание сессий и блокировок времени из планировщика;
* напоминания о сессии клиенту и специалисту примерно за сутки и за час до записи;
* базовая платежная архитектура с webhook-обработкой;
* email и Telegram-уведомления;
* feature flags для включения и отключения модулей;
* настройки, позволяющие собирать разные версии продукта: от более простого лендинга до расширенной версии с CRM, записью, отзывами, пакетами и планировщиком;
* тесты для ключевой бизнес-логики и API-сценариев.

Проект задуман как основа, которую можно адаптировать под разных специалистов и разные уровни продукта: от простого лендинга до связки “лендинг + CRM + онлайн-запись + отзывы + пакеты + планировщик”.

## Основной функционал

### Публичный сайт

* адаптивный landing page с отдельной проработкой desktop, tablet и mobile-версий;
* адаптация под реальные viewport-размеры (а не только "паспортные") устройств, включая iPad 9 и iPhone 13 Pro Max;
* секции Hero, About, Education, Pricing, Reviews, Booking, Contacts и FAQ;
* SEO-настройки и Open Graph-превью для корректного отображения ссылок в поиске, соцсетях и мессенджерах;
* контент сайта вынесен в конфигурационные файлы `src/data`, что упрощает адаптацию шаблона под разных специалистов;
* опциональная мультиязычность RU / EN;
* опциональная светлая / темная тема;
* опциональная Яндекс.Метрика;
* floating CTA-кнопка для быстрой записи, сопровождающая клиента по сайту.

### Онлайн-запись

* отдельная страница `/book`;
* выбор услуги, даты и доступного свободного слота;
* обычная запись на разовую услугу;
* режим покупки пакета;
* запись по коду уже купленного пакета;
* проверка доступности слота перед созданием записи;
* защита от двойного бронирования одного и того же времени;
* обработка конфликтов записи, если слот был занят другим клиентом во время оформления;
* автоматическое исключение из записи занятых слотов, вручную заблокированного времени и нерабочих интервалов;
* настройка перерыва между сессиями / услугами, чтобы избежать слишком плотной записи;
* учет рабочего расписания специалиста, недельных правил и исключений по конкретным датам;
* skeleton/loading states;
* email и Telegram-уведомления;
* напоминания клиенту и специалисту перед сессией;
* строгая backend-валидация контактных данных и сообщения.

### CRM / админка

* авторизация администратора;
* заявки с поиском, фильтрами, статусами и отдельным блоком старых заявок;
* клиенты с ручным созданием, редактированием, поиском, фильтрами, возможностью сделать клиента “избранным” и защитой от дублей;
* услуги с возможностью ручного создания и редактирования;
* пакетные планы на основе услуг;
* выдача клиенту пакета услуг;
* сессии с ручным созданием, редактированием и связью с клиентом / услугой / пакетом;
* заметки по клиентам;
* настройки личного расписания специалиста;
* недельные правила работы;
* исключения по конкретным датам;
* блокировки времени и перерывы;
* публичные отзывы, модерация и управление порядком показа;
* отдельные блоки, фильтры и поисковые сценарии там, где это нужно для удобной работы с накопленными данными без лишней загрузки всей истории из БД;
* инструкция для новых пользователей админки;
* интерактивный премиум-календарь “Планировщик” (scheduler).

### Планировщик / Scheduler

Планировщик — это опциональный интерактивный премиум-календарь для специалиста.

В нем предусмотрены:

* режим недели;
* режим дня;
* основа для режима месяца;
* отображение сессий в календарной сетке;
* отображение заблокированного времени;
* отображение нерабочих интервалов;
* просмотр деталей дня;
* просмотр деталей сессии;
* создание сессии из свободного слота;
* создание блокировки времени / перерыва из свободного слота;
* разные сценарии взаимодействия для desktop, tablet и mobile.

Цель планировщика — дать специалисту более наглядный способ управлять расписанием, а не только работать через таблицы и формы.

На мобильных устройствах создание сессии или блокировки из свободного слота работает через долгое нажатие, чтобы избежать случайных действий при обычном скролле.

### Отзывы

* публичная форма отзыва;
* проверка клиента по email или телефону;
* проверка наличия подходящей сессии;
* защита от ситуации, когда отзыв оставляет человек, который не пользовался услугой специалиста;
* модерация отзыва перед публикацией;
* статусы: ожидает модерации (`pending`), опубликован (`published`), скрыт (`hidden`);
* публичный список отзывов;
* карусель отзывов на лендинге;
* закрепление отзывов и управление порядком отображения в админке;
* базовая защита от запрещенного контента и спам-повторов.

### Пакеты сессий

* создание пакетных планов на основе обычных услуг;
* настройка количества сессий в пакете;
* настройка цены пакета;
* удобный ввод цены в админке с разделением разрядов, например `3.451.000`;
* генерация кода пакета;
* выдача пакета конкретному клиенту;
* запись по коду пакета;
* связь сессии с пакетом;
* учет использованных и оставшихся сессий;
* логика, при которой отмененная сессия не расходует пакет, а проведенная или пропущенная клиентом сессия учитывается.

### Напоминания и уведомления

В проекте реализованы разные типы уведомлений:

* уведомление специалисту о новой заявке;
* уведомление клиенту после отправки заявки;
* уведомление специалисту о новой записи;
* уведомление клиенту о созданной записи;
* уведомление о покупке пакета;
* напоминание клиенту и специалисту примерно за сутки до сессии;
* напоминание клиенту и специалисту примерно за час до сессии.

Для отправки используются email через Resend и Telegram Bot API. Периодический запуск reminder-логики организован через внешнюю cron-интеграцию.

### Платежная архитектура

В проекте есть базовая платежная архитектура для покупки пакетов и будущего расширения платных сценариев.

Реализованы:

* создание платежа;
* payment success page;
* webhook-обработка платежных событий;
* проверка webhook-событий;
* финализация успешной оплаты;
* создание пакета после подтверждения оплаты;
* защита от повторной финализации одного и того же платежа;
* rollback-логика при ошибках во время финализации;
* тесты на payment finalization и webhook security.

Документация по тестовой оплате через ЮKassa находится в:

## Безопасность и надежность

В проекте реализованы:

* HTTP-only cookie для admin session;
* защита admin API;
* HTML escaping пользовательских данных в email-уведомлениях;
* rate limiting публичных POST-действий через PostgreSQL;
* строгая backend-валидация контактных данных;
* единая валидация телефона, email, имени и фамилии;
* ErrorBoundary для защиты UI от полного падения экрана;
* webhook security foundation для платежных событий;
* защита от повторной финализации платежа;
* приватный словарь запрещенных слов не хранится в репозитории.

Rate limiting применяется к действиям:

* отправка публичной заявки;
* отправка отзыва;
* создание записи;
* проверка пакета;
* создание платежа.

## Локальный запуск

Установка зависимостей:

```bash
npm install
```

Запуск frontend:

```bash
npm run dev
```

Для локальной работы с Vercel Serverless Functions используется отдельный запуск:

```bash
npx vercel dev --listen 127.0.0.1:3002
```

В текущем workflow frontend открывается через Vite, а `/api` запросы проксируются на Vercel dev.

## База данных

Проект использует PostgreSQL.

Миграции хранятся в:

```text
database/migrations
```

Миграции применяются вручную к локальной и production-базе, чтобы схема была воспроизводимой и не существовала только в pgAdmin / Neon.

## Архитектура

Основные директории:

```text
src/
  app/              # app providers и router
  components/       # переиспользуемые UI-компоненты
  data/             # контент, настройки, feature flags
  layouts/          # публичный и admin layouts
  lib/              # frontend helpers и API-клиенты
  pages/            # public и admin pages
  sections/         # секции лендинга
  styles/           # глобальные стили и переменные
  types/            # общие типы

api/                # Vercel Serverless API routes
server/             # server-side бизнес-логика
database/           # SQL migrations
public/             # статические assets
```
