# YooKassa testing notes

В проекте используется тестовый магазин ЮKassa для проверки платежного сценария.

## Что важно помнить

- Для тестирования нужно использовать **идентификатор и секретный ключ именно тестового магазина**.
- В тестовом режиме деньги **никуда не переводятся**.
- В тестовом магазине можно проверять:
  - оплату **банковской картой**
  - оплату через **кошелек ЮMoney**
- Для нашего сценария webhook должен быть настроен на:

`https://psychologist-landing-template.vercel.app/api/payment?action=webhook`

## HTTP-уведомления

В тестовом магазине должны быть включены как минимум события:

- `payment.succeeded`
- `payment.canceled`

URL для уведомлений:

`https://psychologist-landing-template.vercel.app/api/payment?action=webhook`

## Тестовые карты — успешный сценарий

Можно использовать, например:

- `4111 1111 1111 1111`
- `5555 5555 5555 4444`
- `5555 5555 5555 4477`
- `2200 0000 0000 0004`
- `2202 4743 0132 2987`

## Тестовые карты — неуспешный сценарий

Можно использовать, например:

- `5555 5555 5555 4535` — отклонение платежа
- `5555 5555 5555 4543` — карта просрочена
- `5555 5555 5555 4600` — недостаточно средств
- `2200 0000 0000 0038` — карта Мир, просрочена

## Данные для ввода при тесте

- Срок действия: **любой месяц/год в будущем**
- CVC/CVV: **любые 3 цифры**
- 3-D Secure код: **любые цифры**
